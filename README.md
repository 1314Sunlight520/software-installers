# 软件安装包仓库

本仓库用于集中保存各类软件安装包，便于在不同设备之间下载和使用。

## 目录规划

安装包统一按照以下层级组织：

`文件/软件名称/版本/平台/架构/安装包文件`

示例：

- `文件/Python/3.7.8/Windows/x64/`
- `文件/Python/3.12.8/macOS/arm64/`
- `文件/Python/3.12.8/Linux/x64/`
- `文件/某个应用/1.0.0/Android/arm64/`
- `文件/某个应用/1.0.0/iOS/arm64/`

每个软件版本对应的说明和校验信息保存在 `清单/软件名称/版本/版本清单.json`。

## 平台和架构命名

- Windows：`x86`、`x64`、`arm64`
- macOS：`x64`、`arm64`
- Linux：`x86`、`x64`、`arm64`
- Android：`arm64`、`armeabi-v7a`、`x64`
- iOS：`arm64`

## 下载与校验

下载后建议使用 SHA-256 校验文件完整性。版本清单中的文件大小和 SHA-256 值以实际上传文件为准。

## 注意事项

本仓库目前为公开仓库。上传文件前请确认其中不包含个人隐私、授权凭据或其他不适合公开传播的内容。
